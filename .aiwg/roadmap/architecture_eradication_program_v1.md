# Architecture Eradication Program (AEP) v1.0.0

## Purpose
Conectar estabilidad técnica con evolución estratégica de largo plazo.

## Horizons
- Corto plazo (0-2 semanas): integridad de ejecución y contratos base.
- Mediano plazo (1-3 meses): convergencia de arquitectura y reducción de acoplamientos.
- Largo plazo (3-12 meses): sostenibilidad automática gobernada por métricas.

## Scope Sequence
1. `layers/` (L0-L1-L2): corregir integridad, rutas, fronteras y dependencias.
2. `.aiwg/`: formalizar contratos de auditoría, KPIs y ciclos de checkpoint.
3. `repo completo`: institucionalizar gates, plantillas PR y disciplina sostenible.

## KPI Targets
- `kpi.layer_inversion`: 0 dependencias L2->L1.
- `kpi.hardcoded_abs_runtime`: 0 rutas absolutas críticas nuevas.
- `kpi.syntax_integrity_py`: all first-party `.py` compilables.
- `kpi.audit_gate_pass_rate`: >= 95% en 4 semanas.
- `kpi.regression_test_on_bugfix`: full de bugfixes con test nuevo/actualizado.

## Governance Cadence
- Semanal: checkpoint operativo (bloqueos, riesgos, entregables).
- Mensual: revisión de deuda y avance de migración.
- Trimestral: revisión filosófica de objetivo largo y evolución de meta.
