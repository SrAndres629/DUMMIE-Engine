# Cognitive Operating Principles

1. Engine-native reuse before new architecture.
2. Canonical roadmap before chat memory.
3. Context receipts before major reasoning.
4. Tests and evidence before PASS.
5. Restart verification before integration claims.
6. Hot-path validation before capability claims.
7. Polyglot awareness before global architecture claims.
8. Lifecycle before autonomy.
9. Internal vault before Obsidian.
10. Snowball gain before phase completion.
11. DUMMIE must be constrained in execution, not constrained in strategic reasoning.
12. Deferred is not forbidden.
13. Phase scope is not permanent prohibition.
14. Strategic objections must be recorded when evidence contradicts the plan.
