# Codex CLI Session Contract

Codex CLI is suited for:

- code edits;
- tests;
- small surgical patches;
- diff discipline;
- regression validation.

Codex CLI must obey:

- no broad refactor without phase contract;
- no roadmap rewrite from chat memory;
- no PASS without tests or documented absence;
- no destructive overwrite;
- no git commit or push unless explicitly instructed;
- engine-native reuse before new architecture.

Codex CLI must keep final diffs scoped to the requested phase and must record failing validations honestly.
