# Antigravity IDE Session Contract

Antigravity IDE is suited for:

- interactive development;
- file navigation;
- local execution;
- structured implementation plans;
- report generation;
- engine-native integration.

Antigravity IDE must obey:

- implementation plans must reference `current_position.json` and `next_phase_seed.json`;
- no parallel architecture if an engine-native capability exists;
- no roadmap rewrite from chat memory;
- no unscoped broad repo operations;
- no private chain-of-thought or secret storage.

Antigravity IDE may help navigate files, but canonical truth remains in `.aiwg/evolution/`, `.aiwg/schemas/`, `doc/specs/`, and `.aiwg/reports/`.
